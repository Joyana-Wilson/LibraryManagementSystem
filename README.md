# LibraryManagementSystem
This is a console based system that has an on screen menu that allows the librarian to manage patrons.
The librarian will be able to add patrons to the LMS from a text file or manually from the command line interface (CLI), remove patrons, or see a list of patrons within the Library Management System (LMS). 
Connection to a relational database is outside the scope of work for this project. Any and all data will be stored directly within the console-based Java application.
